# Python Libraries

This page lists the Python libraries used in STA272 course materials with links to their official documentation.

## Data Manipulation and Analysis

- [pandas](https://pandas.pydata.org) - Data manipulation and analysis library
- [NumPy](https://numpy.org) - Numerical computing library

## Data Visualization

- [Matplotlib](https://matplotlib.org) - Plotting and visualization library

## Machine Learning

- [scikit-learn](https://scikit-learn.org/stable/index.html) - Machine learning library

## Statistical Modeling

- [statsmodels](https://www.statsmodels.org) - Statistical models and tests

## Web Scraping and HTTP

- [Requests](https://requests.readthedocs.io) - HTTP library for making web requests
- [Beautiful Soup](https://www.crummy.com/software/BeautifulSoup/bs4/doc/) - HTML and XML parsing library
